# Database Bootstrap Strategy — SmartCheck Phase 1This document outlines the architecture constraints and bootstrapping strategies for the database schema in new environments (production, staging, or fresh local checkouts).## 1. Migration Nature: SmartCheck DeltaThe initial migration file `drizzle/0000_fair_thing.sql` is a **delta migration**. It does not build the entire database schema from scratch. Instead, it expects the existing 18 baseline tables of TeklifPro to be present in the target database.> [!WARNING]> Running `npx drizzle-kit migrate` on a completely empty PostgreSQL database will **FAIL** because the delta migration references existing tables (e.g., `companies`, `users`, `memberships`, `quotations`) that are not created within this migration file.## 2. Bootstrapping New EnvironmentsTo initialize a completely fresh environment (e.g., local development for a new developer, a staging database, or production deployment), the following sequence must be observed:1. **Restore Baseline Schema:**   Apply the baseline schema definitions (the 18 tables) using the original schema creation SQL or by restoring a clean database dump.2. **Apply Delta Migrations:**   Run the Drizzle Kit migrations tool to apply the SmartCheck delta migrations:   ```bash   npx drizzle-kit migrate   ```## 3. Strict Rules and Constraints- **No Staging/Production Execution:** Migration approval is currently restricted strictly to `teklifpro_local`. Production/staging migrations are **NOT** approved yet.- **No Manual Metadata Edits:** Do not manually edit the migration journal (`drizzle/meta/_journal.json`) or the snapshot file (`drizzle/meta/0000_snapshot.json`).- **No Manual Database History Injection:** Never manually insert records into the `drizzle.__drizzle_migrations` table on any database. Always let Drizzle Kit manage the migration lifecycle.- **Bootstrap Strategy Evolution:** A unified bootstrapping strategy to merge the baseline schema and delta migrations into a single, clean initialize script will be designed and approved prior to the deployment milestone.
