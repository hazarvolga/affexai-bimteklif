## Verified source claims

1. A Building Structure organizes drawing files in hierarchical levels and is directly linked to the plane model. Drawing files assigned to a structural level can use that level's default planes.
2. Building Structure operations can assign drawing files and planes to structural nodes and update drawing files when plane assignments change.
3. Views, sections and reports can be derived from the Building Structure; these outputs depend on the modeled objects and their assigned data.
4. Architectural elements carry geometry and quantity attributes that can be evaluated in reports. Report results reflect the component geometry, material and calculation mode entered in the model.
5. Model organization, quantities and reports do not prove structural capacity. Load paths, actions, combinations, member resistance and code compliance require engineering analysis outside this evidence pack.
