# Structural Drawings — ALLPLAN 2026 Official Source Pack

**Source ID:** `p3-c4-m1`

**Module:** Structural drawings

**Target version:** ALLPLAN 2026-1

**Status:** Source draft only; workstation evidence and technical approval are still required.

## Verified source claims

1. Views can be created under the Views node of the Building Structure and assigned to dedicated drawing files.
2. Generate View provides settings for the derived view; an axis grid can be displayed in the resulting view.
3. Views and sections can reference model data across drawing files. Model and derived-output files therefore require controlled current/edit status for modification.
4. New 3D components are automatically transferred into Views and Sections outputs, but generated output still requires revision and annotation checks.
5. A generated drawing is not construction-ready merely because it is associative; scale, scope, axes, dimensions, labels, revisions and issue status require review.
