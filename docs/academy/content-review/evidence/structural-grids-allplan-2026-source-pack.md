## Verified source claims

1. Axis Grid creates freely arranged axis lines with configurable spacing, display properties and labels in x and y; z-direction spacing can create multiple planes.
2. The Axis Grid palette defines rotation, x/y axis counts and distances, angles, projections, z-direction copies, labels and a grid name.
3. A live preview is attached to the crosshairs before placement. Point handles and palette values support later exact movement, rotation, spacing and angle changes.
4. Default numbering updates when axes change or are deleted; custom text does not automatically label newly added axes.
5. ALLPLAN's IFC element filter maps a 3D axis grid to `IfcGrid`. This confirms exchange classification, not structural-member alignment or engineering adequacy.
